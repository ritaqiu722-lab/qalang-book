# mnanak na qalang 互動繪本

可翻頁、有旁白與配樂的互動繪本網頁(純 HTML/CSS/JS,不需要建置)。

## 檔案結構

```
index.html        主頁面(所有功能都在這裡)
img/              p0~p19.jpg 為 20 頁插圖;left/right/read/spirit 為介面圖示(png 透明背景)
audio/            speech0~19 旁白、music0~19 每頁配樂、bgm.mp3 封面主題曲
.nojekyll         告訴 GitHub Pages 不要用 Jekyll 處理
```

## 操作

- 點封面「開始閱讀」(瀏覽器規定要有互動才能播放聲音);按下一頁、方向鍵或「朗讀」也會自動開始
- 翻頁:左右箭頭、鍵盤 ← →、手機左右滑動。第 1 頁沒有上一頁、第 20 頁沒有下一頁(按鈕會停用),末頁有「回到封面」
- 下方按鈕:
  - **朗讀**:朗讀目前這一頁(連按只會從頭重播,不會疊聲);朗讀時配樂自動降到約 1/4 音量,讀完或暫停後恢復
  - **靜音 / 解除靜音**:一次關閉或開啟全部聲音,翻頁後仍保持
  - **自動播放**:每頁自動朗讀,讀完自動翻頁(預設關閉)
  - **除錯**(快捷鍵 D):顯示目前頁面、各音檔狀態與音量、預載清單、最近記錄
- 空白鍵:朗讀 播放 / 暫停
- 翻頁會立刻停止上一頁的朗讀,並切換成新一頁的配樂
- 下一頁的圖片、朗讀、配樂會事先預載
- 素材載入較慢時左上角會顯示「載入中…」;載入失敗會出現說明與「重試」按鈕
- 網址 `#5` 可直接跳到第 5 頁

## 調整

`index.html` 的 `<script>` 開頭有設定區:

- `MUSIC_VOL` 每頁配樂音量、`VOICE_VOL` 朗讀音量、`BGM_VOL` 主題曲音量、`DUCK` 朗讀時配樂降到幾倍
- `AUTO_DEFAULT` 設成 `true` 則預設開啟自動播放
- `BGM_ONLY_ON_COVER` 設成 `false` 則主題曲全書低音量循環播放
